# 车掌柜 Car Manager

> 汽修店维修工单 · 记账 · 赊账 · 保养提醒 一站式管理系统
> 原生 HTML + PHP + MySQL 实现，无任何框架依赖，上传即可部署

面向中小汽修店 / 快修店 / 保养店，老板一台手机或电脑即可管理全店业务：记工单、看流水、追欠款、提醒保养。员工（徒弟）可以开单但看不到金额，多店铺可统一由超管后台管理。

## ✨ 功能特性

- **记一笔（工单）**：按车牌快速检索车辆，常用项目点选自动合计金额，支持拍照识别车牌（百度 OCR）
- **赊账管理**：收款方式可选"已收款 / 赊账"，待收款一键筛选，结清即更新
- **保养提醒**：按"月数 / 里程"设置下次保养提醒，默认提醒周期可在设置中自定义
- **员工权限**：老板（boss）与徒弟（staff）两种角色，徒弟开单但看不到金额
- **多店铺 SaaS**：店铺开通 / 停用、到期时间管理，超管后台统一查看数据、发布公告
- **车辆管理**：车牌、车主称呼、电话、车型颜色、标签，输入车牌自动匹配
- **工单照片**：现场照片多张上传留档，支持手机拍照
- **常用项目库**：预置 10 个常用项目，点选即填、自动算价，可自行增删改
- **记录统计**：今天 / 本周 / 本月 / 全部 / 待收款筛选，单数、总额、赊账一目了然

## 🛠 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | 原生 HTML + JavaScript（响应式，手机 / 电脑自适应，无框架） |
| 后端 | PHP 7.4+（原生，无框架） |
| 数据库 | MySQL 5.7+ |
| 车牌识别 | 百度 OCR（后台可配置 API Key） |

## 🚀 部署步骤

服务器要求：PHP 7.4+、MySQL 5.7+、Nginx / Apache

1. 把仓库所有文件上传到网站根目录
2. 创建数据库，导入 `install.sql`
3. 修改 `config.php` 里的数据库账号密码（本地修改即可，不会提交到仓库）
4. 访问 `login.html` 注册第一个账号（老板账号）
5. 完成 🎉

### 超管后台

- 地址：`你的域名/admin.html`
- 首次登录默认账号 `admin / admin123`，**登录后请立即在后台修改密码**
- 超管 token 首次访问时自动生成并存入 settings 表（admin_token），部署后请通过数据库查看并妥善保管
- 可查看所有店铺数据、发布公告、开通 / 停用店铺

### 使用注意

- 徒弟账号在 `staff.html` 管理，徒弟看不到金额
- 常用项目在 `items.html` 修改，已预置 10 个示例
- 默认提醒周期在 `settings.html` 修改
- 车牌 OCR 需在超管后台配置百度 OCR 的 API Key

## 🔒 安全提示

- 部署后请立即修改超管默认密码与数据库密码
- 生产环境建议开启 HTTPS
- 数据库账号建议使用最小权限账号，不要把 root 密码写进 `config.php`
